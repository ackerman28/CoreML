# Linear Regression Example

This example demonstrates the Ordinary Least Squares (OLS) implementation of Linear Regression.

- [Analysis Notebook](./regression_analysis.ipynb): Shows the model fitting a line to noisy synthetic data and calculates $R^2$ and MSE.

### Key Concepts
- **Normal Equation**: Solving for weights analytically without gradient descent.
- **Evaluation**: Using $R^2$ to measure how much variance the model explains.
