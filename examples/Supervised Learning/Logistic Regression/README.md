# Logistic Regression Example

Implementation of a binary classifier using Gradient Descent and the Sigmoid activation function.

## Contents
- [logistic_analysis.ipynb](./logistic_analysis.ipynb): A notebook demonstrating the model's ability to find a linear decision boundary on the 'Moons' dataset.

## Highlights
- **Sigmoid Activation**: Mapping linear outputs to probabilities.
- **Feature Scaling**: Demonstrates why `StandardScaler` is crucial for Gradient Descent performance.
